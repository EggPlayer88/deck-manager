## `skill-components-2026-05.json`

2026-05-03 커밋 시점의 **스킬 점수 산정 데이터**.

당시 방식은 스킬 하나를 능력치별 성분으로 쪼개어 보관하고, 점수를 그때그때 계산했다.

```
점수 = Σ (상승치 × 빈도 × 능력치 가중치)
     = pV*pF*w.p + aV*aF*w.a + eV*eF*w.e + cV*cF*w.c + sV*sF*w.s
```

덕분에 **가중치를 바꾸면 모든 스킬 점수가 자동으로 다시 계산**되는 장점이 있었다.

### 왜 걷어냈나

덱 보정 시트(260814)는 성분이 아니라 **레벨별 최종 점수**만 제공한다.
성분 방식으로는 시트 값을 정확히 재현할 수 없어서(타자 기준 평균 오차 약 1.0점),
2026-09-08에 시트의 최종 점수를 그대로 쓰는 방식으로 바꿨다.

### 들어 있는 것

| 키 | 내용 |
| --- | --- |
| `weights` | 당시 가중치 `p 1.0 · a 0.9 · e 0.3 · c 1.175 · s 1.275` |
| `skills.타자` | 84종 |
| `skills.선발` | 70종 |
| `skills.중계` | 83종 |
| `skills.마무리` | 65종 |

각 스킬은 `[Lv5 … Lv10]` 6개 원소이고, 원소마다
`{pV,pF,aV,aF,eV,eF,cV,cF,sV,sF}` 형태다.

### 다시 쓰려면

`src/deck-manager.jsx`의 `getSkillScore`는 **두 형식을 모두 지원**한다 —
원소가 숫자면 그 값을 그대로 쓰고, 객체면 성분 × 가중치로 계산한다.
따라서 이 파일의 `skills` 를 `DEFAULT_SKILLS` 자리에 넣으면 예전 방식으로 돌아간다.
