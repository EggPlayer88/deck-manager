# 선수사진

작업한 사진을 여기에 넣어 두면 됩니다. **폴더째로 넣어도 됩니다.**

```
선수사진/
  _현재 웹앱 적용중/     ← 참고용. 지금 웹에 올라가 있는 사진들 (올리기 대상 아님)
  20260929 작업분/
    이승엽1.png
    이승엽2.png
    김도영.png
```

하위 폴더를 전부 훑으므로 작업 단위로 폴더를 만들어 던져 넣기만 하면 됩니다.
**폴더 이름은 정리용일 뿐 매칭에 쓰이지 않습니다.** 매칭은 파일명으로만 합니다.
`_` 로 시작하는 폴더는 참고·보관용으로 보고 **건너뜁니다.**

## 파일명 규칙

```
이승엽.png     ← "이승엽" 카드에 붙음
이승엽1.png    ← 같은 선수의 1번 사진
이승엽2.png    ← 같은 선수의 2번 사진 (유저가 카드에서 골라 쓸 수 있음)
```

- 이름 뒤의 숫자는 **같은 선수의 여러 장**을 구분하는 용도입니다.
- 카드에 기본으로 뜨는 건 **파일명 순 첫 번째** 사진입니다.
- 선수 이름은 선수도감에 등록된 이름과 **정확히** 같아야 매칭됩니다.
  동명이인 접미사도 그대로 써야 합니다 — `로하스B.png`, `김현수B.png`
- 서로 다른 폴더에 같은 파일명이 있으면 하나가 다른 하나를 덮어씁니다 (실행할 때 경고).

## 팀이 다르면 유니폼도 다릅니다

같은 선수라도 팀을 옮겼으면 **팀별로 사진을 따로** 붙일 수 있습니다.
이름 뒤에 `_팀이름` 을 붙이면 됩니다.

```
최형우_삼성.png     ← 삼성 최형우 카드에만
최형우_기아.png     ← 기아 최형우 카드에만
최형우_기아2.png    ← 기아 최형우의 2번 사진
최형우.png          ← 팀 무관. 위에 없는 팀의 기본이 됨
```

고르는 순서는 **팀 일치 → 팀 무관 → 없음** 입니다.
팀을 안 붙이면 그 선수의 모든 팀 카드에 같은 사진이 붙습니다 (지금 올라간 20장이 그렇습니다).

**쓸 수 있는 팀 이름** (도감과 똑같이):

```
키움 · 삼성 · LG · 두산 · KT · SSG · 롯데 · 한화 · NC · 기아
```

> `최형우_KIA.png` 처럼 도감에 없는 이름을 쓰면 팀으로 인식되지 않아
> **어떤 카드에도 안 붙습니다.** 올릴 때 경고가 뜨지만 막지는 않으니 확인해 주세요.

도감 1,085명 중 **190명이 팀이 둘 이상**입니다. 사용 순위 상위 100명 중에는 36명이고,
1위 최형우(삼성·기아), 2위 박병호(KT·키움), 7위 양의지(LG·두산·NC)가 여기 해당합니다.

## 사진 규격

| 항목 | 규격 |
| --- | --- |
| **배경** | **투명 (누끼)** — 카드의 그라데이션이 비쳐 보이는 것이 이 앱의 스타일 |
| **비율** | **2:3 세로** (예: 1024×1536) |
| 형식 | 알파 채널이 있는 **PNG** 또는 WebP. **JPEG 금지 — 투명도가 사라집니다** |
| 크기 | 아무 크기나. 올릴 때 600×900 안으로 **축소만** 합니다 (자르지 않음) |

### ⚠ 카드에 보이는 건 위에서 6% ~ 74% 구간입니다

카드의 사진 칸이 거의 정사각형이라, 2:3 사진은 **위아래가 잘립니다.**
잘리는 위치는 **모든 사진에 동일하게 고정**되어 있습니다 (예전엔 선수별 슬라이더가
있었지만, 위치가 사진마다 달라지면 구도를 잡을 수 없어 없앴습니다).

```
   0% ┌──────────┐
      │  잘림     │  ← 위 6%
   6% ├──────────┤
      │          │
      │ 보이는 구간 │  ← 얼굴·상체를 여기에
      │          │
  74% ├──────────┤
      │  잘림     │  ← 아래 26% (발끝은 안 보입니다)
 100% └──────────┘
```

같은 폴더의 `사진규격_가이드.png` 를 작업 파일에 깔고 맞추면 편합니다.
sm·md·lg 세 카드 크기 모두에서 안전한 구간으로 잡아 둔 값입니다.

## 올리기

```bash
npm run photos
```

올릴 때 이렇게 처리됩니다.

```
투명 PNG 2.4MB  →  알파를 지킨 WebP 90KB  (약 26배 축소)
```

| 옵션 | 하는 일 |
| --- | --- |
| `npm run photos -- --dry` | 올리지 않고 무엇을 할지만 보여줌 |
| `npm run photos -- --force` | 이미 올린 것도 전부 다시 올림 |
| `npm run photos -- --manifest-only` | 업로드 없이 목록만 다시 맞춤 |

올리고 나면 **재배포 없이** 웹에 바로 반영됩니다.

## 참고

- 이 폴더의 사진은 git 에 올라가지 않습니다 (원본 보관용).
- 한 번 올린 사진은 다음 실행 때 건너뜁니다 (`.sync-cache.json` 이 기억합니다).
- 올린 뒤에도 파일을 여기 그대로 두면 됩니다. 지우거나 옮길 필요 없습니다.
